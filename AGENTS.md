# Public Site Version Policy

- V9 is the canonical public Serenity dashboard.
- `index.html` must be assembled from `dashboard/analysis_site_static_clone_v9.html` in the source workspace.
- V7 directories are historical compatibility assets and must never become the homepage again without explicit user approval.
- Publish from the `main` branch and verify GitHub Pages after pushing.
- Preserve unrelated uncommitted generated ticker-page changes; stage only the files required by the current publication.
- Before publishing a newly approved homepage article, confirm that the source workspace archived it under `reports/published/homepage/` and updated the archive index.
