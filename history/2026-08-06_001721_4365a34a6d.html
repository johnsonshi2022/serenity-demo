推理定价权：DeepSeek 涨价与 300 亿美元/吉瓦的 ARR 意味着什么

8月6日，DeepSeek 预告将对全部 API 服务整体上调价格、且涨幅较大；同一周，第三方测算显示每吉瓦推理容量的年化收入已升至约 300 亿美元。一边是涨价，一边是需求二次加速，token 的定价权到底在谁手里？本文用官方公告、官方技术报告、公开价目表与公众号测算四条线索，拆解这个可以证伪的问题：涨价是价格战的终点，还是长期成本下行中的一次插曲。

Part 01

先说结论：涨价是真的，但更可能是长期成本下行中的一次短暂再定价

8月6日，DeepSeek 在官方渠道预告，计划近期对 API 服务整体上调价格，预计涨幅较大，具体方案以正式通知为准。【1】同一天前后，市场开始用“token 定价权”重新讲述这个故事：有的测算 V4-Pro 名义毛利率可达 90% 至 97%、扣除免费流量后真实毛利率约 72% 至 81%【4】；有的转述第三方估算称，每吉瓦推理容量对应的年化收入今年已上升约 50%、达到约 300 亿美元【5】。两条线索合在一起，最自然的解读是“价格战结束、涨价周期开启”。

本文的判断是：DeepSeek 涨价是真实信号，但它更像“算力稀缺乘以需求二次加速”下的短期再定价，而不是单位 token 成本长期下行趋势的逆转。模型架构、芯片代际和推理工程仍在快速降本——MoE 训练吞吐刚刚被开源工程证明还能再提高 40% 以上【6】【7】。真正决定产业链价值分配的，不是某一次涨价，而是用量弹性能否持续跑赢价格波动，以及谁能把效率提升变成利润，而不是只让利给用户。

因此，本文要回答一个可证伪的问题：DeepSeek 涨价与 300 亿美元/吉瓦的 ARR，究竟是“价格战结束的拐点”，还是“长期成本下行曲线上的一次短暂再定价”？如果涨价落地后付费调用量显著下滑，说明定价权只是暂时的；如果涨价同时用量仍增长、头部实验室 ARR 持续上修，说明稀缺算力确实拥有了定价权。两种结果对应完全不同的投资含义。

  • 官方事实：涨价预告属实，但幅度与生效时间未定。【1】
  • 关键推断：短期定价权来自稀缺，不改变长期单位成本下行。
  • 证伪锚点：涨价后的调用量弹性与 ARR/吉瓦 环比方向。
Part 02

官方事实：涨价预告、现行价目表与尚未生效的峰谷定价

按公开转述的官方口径，DeepSeek 于 8 月 6 日预告将对全部 API 服务整体上调价格，并强调“预计涨幅较大”，具体方案以正式通知为准。本次运行中，官方价格页无法直接访问（访问被限制），涨价预告与价目表经中新网、财联社等媒体转述核对，因此全部标注为“官方公告/媒体转述”层级，最终以官方正式通知为准。【1】

现行价目表（媒体转述口径，截至 2026-08-06）：V4-Flash 为每百万 tokens 0.02 元（缓存命中）、1 元（缓存未命中输入）、2 元（输出）；V4-Pro 为每百万 tokens 0.025 元、3 元、6 元。另有媒体转述的峰谷定价方案：北京时间 9:00 至 12:00、14:00 至 18:00 为高峰时段，价格约为基础价的 2 倍；该方案尚未生效。【1】

从量看，第三方统计口径显示，V4-Flash 在 8 月 1 日单日处理约 8 万亿 tokens，其中约 5 万亿为免费流量、3 万亿为付费流量【第三方口径，原始链接待核】；8 月 4 日又因访问量空前出现容量压力，官方确认了当日服务压力【媒体转述】。若按此拆算，免费流量占比仍然很高，这也解释了为何市场普遍推断涨价的重要动机之一是“过滤低价与免费调用、把稀缺算力留给付费能力更强的用户”——该动机属于市场推断，不是官方表述。

融资与估值背景同样重要：8 月 5 日，21财经与《财经》等媒体报道 DeepSeek 新一轮融资前估值约 5000 亿元人民币、拟融资约 500 亿元【媒体转述，原始链接未归档】。对一家仍需要持续购买算力、扩大集群的私营公司，涨价与融资可以看作同一件事的两面：让 API 业务更接近自我造血，同时为下一轮资本开支定价。

  • 已确认：涨价预告（官方公告，媒体转述）；具体幅度与生效时间未定。【1】
  • 现行价：V4-Flash 0.02/1/2 元、V4-Pro 0.025/3/6 元每百万 tokens（转述口径）。【1】
  • 背景：单日约 8 万亿 tokens（第三方统计）、8/4 容量承压、约 5000 亿元融资前估值（媒体转述）。
Part 03

账本拆解：官方 545% 口径与 V4-Pro 的名义/真实毛利率

讨论定价权之前，先看成本账。DeepSeek 官方系统论文（2025 年 3 月，V3/R1 线上推理系统）披露：日均使用约 226.75 个 H800 节点，单日处理约 6080 亿输入 tokens 与 1680 亿输出 tokens；按每张卡每小时 2 美元的租赁价格测算，单日 GPU 成本约 8.7 万美元；若全部按当时 R1 的 API 价格计费，理论日收入约 56.2 万美元，对应理论收入成本利润率约 545%。【3】

官方论文同时强调，545% 是理论口径：网页端与 App 免费、夜间折扣、低价版本与未完全计费流量，都会大幅压低真实收入。【3】因此 545% 不能直接当真实利润率，但它证明了一个方向性事实：DeepSeek 的推理成本远低于名义牌价，账面并不存在“每卖一个 token 就亏钱”的困境。

到 V4，公开测算进一步放大这个结论。公众号《傅里叶的猫》按 V4-Pro 名义牌价、模型推理计算量下降与缓存机制改善推算，名义毛利率可达 90% 至 97%；把免费流量、折扣等因素扣除后，作者估计真实毛利率约在 72% 至 81% 区间。【4】这是作者推断而非官方披露，但即使取下限 72%，也意味着涨价并非因为“无法覆盖成本”，而是主动选择让价格与未来资本开支、稀缺算力对齐。

账本结论：涨价更多是“利润再分配”与“需求筛选”，而不是“成本倒逼”。这决定了后续观察重点应从“DeepSeek 亏不亏钱”转向“涨价之后，付费调用量还能不能继续增长”。

  • 官方口径：R1 时代理论收入成本利润率约 545%，但含大量免费流量，非真实利润率。【3】
  • 作者测算：V4-Pro 名义 90% 至 97%、真实约 72% 至 81%（公众号推断，未官方确认）。【4】
  • 解读：涨价更像主动定价与需求筛选，而非成本倒逼。
Part 04

token 定价权落到数字上：8T tokens/日与 300 亿美元/吉瓦的 ARR

定价权的前提，是稀缺与需求同时存在。需求侧，第三方统计显示 V4-Flash 单日已处理约 8 万亿 tokens，8 月 4 日甚至因访问量空前出现容量压力；供给侧，研报平权转述的海外分析师测算称，每吉瓦推理容量对应的年化收入（ARR）今年已上升约 50%，达到约 300 亿美元/吉瓦，其中企业 API 口径可能更高，约 500 亿美元/吉瓦。【5】

300 亿美元/吉瓦是一个估算，不是官方数据，而且口径差异很大：消费者订阅、企业 API、内部训练占用会给出完全不同的数字。它的价值在于把“推理需求”翻译成“每单位算力能产生多少收入”，这是把 token 定价权落到产业链上的关键换算。按同一测算，2027 年推理算力可能从约 8 吉瓦增至约 31.5 吉瓦：若 ARR/吉瓦维持约 340 亿美元，实验室年化收入可达约 1.1 万亿美元；若效率提升继续推高 ARR/吉瓦，总盘子更高；若供给追上需求，ARR/吉瓦则可能回落至约 276 亿美元，对应约 8700 亿美元年化收入。【5】

三种情景的共同点是“推理收入体量巨大”，分歧在于价格与用量如何分配。DeepSeek 涨价正是在这个节点发生的：当推理需求经历第二次加速（Claude Code 之后，Fable/Codex 带来新一轮增长），撞上交付周期长达 12 至 18 个月的算力供给，掌握稀缺算力的实验室与云厂商自然获得短期定价权。【5】

对投资者而言，300 亿美元/吉瓦不是“利好标签”，而是一个需要逐季验证的换算系数：它上升，说明需求跑赢算力投放；它回落，说明供给开始追上、价格战可能重新开始。后者同样可能发生在 2027 年大规模算力集中上线之后。

  • 需求侧：V4-Flash 单日约 8 万亿 tokens（第三方统计）；8/4 容量承压（官方确认，媒体转述）。
  • 估值锚：ARR/吉瓦 约 300 亿美元，年内上升约 50%（第三方估算）。【5】
  • 情景：2027 算力 8 至 31.5 吉瓦时，ARR/吉瓦决定总盘子是 1.1 万亿、2.8 万亿还是 8700 亿美元级。【5】
Part 05

杰文斯悖论与用量弹性：降价 10% 换 12% 至 18% 用量，涨价呢？

支持“涨价只是插曲”的最强证据，是需求弹性。美股AI投研速递引述 Exponential View 的研究：token 价格每下降 10%，用量上升 12% 至 18%，总 token 收入反而上升。【8】如果这个弹性系数成立，降价的净效果是薄利多销甚至薄利多赚，那么任何一次涨价都在给竞争对手让出份额，长期反而不可持续。

杰文斯悖论的关键前提，是“降价释放了原本负担不起的应用场景”。在 Agent 与编程场景里，成本从一次问答变成一条任务链：一个目标可能对应几十次模型调用与工具执行。单位 token 越便宜，开发者越愿意让 Agent 全天候运行、自我纠错、反复重试，总调用量呈非线性放大——这正是研报平权文章中“两次推理需求加速（Claude Code 与 Fable/Codex）”的直接含义。【5】

但弹性系数本身需要被验证，不能当作常数。12% 至 18% 的用量弹性来自第三方研究引用，而且“用量增长”不等于“收入增长”：降价 10% 只带来 12% 增量时，收入确实微增；如果涨价 50%（DeepSeek 峰谷 2 倍方案的上限），即使用量只回落 15%，收入仍大幅上升。这解释了为什么涨价与“用量仍在增长”可以同时成立——短期收入弹性主要由供给与定价权决定，长期才由杰文斯式的需求创造决定。

因此，杰文斯悖论不是“永远看多算力”的免检证书，而是一个需要逐季跟踪的弹性区间：调用量、任务时长、付费转化率与单 token 价格的乘积，才是真正的收入。

  • 引用弹性：价格每下降 10%，用量上升 12% 至 18%（Exponential View，第三方研究引用）。【8】
  • 结构因素：Agent 任务链把一次问答放大为几十次模型调用与工具执行。【5】
  • 关键区分：用量增长不等于收入增长，要看价格乘以用量的净乘积。
Part 06

开源与工程效率：MoK 把 MoE 训练吞吐提升 41%，成本曲线还在往下走

成本曲线另一侧是工程效率。8 月 4 日，Cursor 开源 Mixture-of-Kittens（MoK）：一个面向 GB200/GB300 NVL72 机架的 MoE 训练 megakernel，官方称在其生产训练栈中把端到端 tokens/s 提升 1.41 倍；单层基准中，MXFP8 前向最快比公开基线快 2.37 倍。【6】【7】第三方转述的测试口径为：跨 512 块 GPU、多个 NVL72 机架的测试中，每 GPU tokens/s 从约 760.9 提升到 1070.2。【6】

MoK 的意义不在“训练快了 41%”本身，而在于它把 MoE 训练瓶颈从计算转向通信：当专家并行规模扩大，token 在不同 GPU 之间搬运的开销成为主约束。DeepSeek-V3 正是 671B 总参数、37B 激活参数的 MoE 架构，arXiv 技术报告披露其训练耗用约 278.8 万 H800 GPU 小时。【2】MoK 证明这类架构仍能通过软件工程继续挖出 40% 级吞吐，而且这条路与 NVL72 硬件形态深度绑定——效率提升与特定硬件深度绑定，既是机会也是门槛。

对成本曲线的含义：单位 token 成本的下行不仅来自芯片代际（H800 到 Blackwell 再到 Rubin），还来自把通信、调度、同步压进单个 kernel 的软件层。这类开源工程会加速“同代硬件处理更多 token”，也就是在名义涨价背后进一步压低真实单位成本。短期定价权来自稀缺，长期成本下行来自这些工程进步，两者并不矛盾。

需要保留的证据边界：MoK 的吞吐数字是 Cursor 自测口径，外部团队能否在不同负载下复现 2.37 倍与 1.41 倍仍需验证；且 MoK 面向 NVL72 专有硬件，不等于通用 MoE 效率的整体提升。【6】【7】

  • 事实：MoK 端到端 tokens/s 提升 1.41 倍，单层 MXFP8 前向最高 2.37 倍（Cursor 自测）。【6】【7】
  • 机制：MoE 训练瓶颈从计算转向通信，效率与 NVL72 深度绑定。【6】
  • 边界：自测口径，外部复现待验证。
Part 07

通胀与通缩并存：短期定价权在卖方，长期定价权回到成本曲线

把前面各节放回同一条时间轴：短期（1 至 2 个季度）是“算力通胀”——稀缺供给、翻倍的高峰定价方案、约 5000 亿元的融资前估值；长期（2 至 3 年）是“单位成本通缩”——芯片代际、缓存命中率提升、MoE 通信优化与开源工程扩散，全部指向“完成同一任务所需算力与成本下降”。【1】【4】【5】【7】

两者的分界点不是某个价格事件，而是算力供给曲线。只要交付周期长达 12 至 18 个月、新增吉瓦跟不上需求，定价权就在卖方；当 2027 年新算力集中上线、ARR/吉瓦开始回落时，价格战可能以“降价加用量扩张”的形式重新开始。【5】DeepSeek 的涨价更接近前者：用价格筛选需求、为资本开支定价，而不是宣告成本曲线逆转。

对“AI 资本开支是否过热”的争论，这条时间轴给出了更精确的问题：不是“Capex 太多”，而是“Capex 在 2026 至 2027 年上线时，ARR/吉瓦能否守住 200 亿美元以上”。守得住，硬件投入可持续；守不住，第一轮价格战会先在推理 API 与裸算力租售中出现，再传导到 GPU 与内存订单。

这也是 Serenity 近期把 NVIDIA/OpenAI 融资结构概括为“信用与循环融资成为新约束”的同一逻辑：AI 基建的可持续性，最终由“算力到 token、token 到收入、收入到现金流”的转化效率决定，而不是由某一轮融资或某一次涨价决定。

  • 短期：稀缺驱动通胀，定价权在卖方。
  • 长期：效率驱动通缩，定价权回到谁成本低、谁生态强。
  • 分界：2027 供给集中上线时，ARR/吉瓦 是核心观测点。
Part 08

收益传导：谁拿到涨价红利，谁在承担涨价成本

如果“涨价加用量增长”同时成立，收益首先流向掌握稀缺算力与定价权的环节：头部模型实验室（API 提价直接增厚收入）、GPU 与 ASIC 供应商（需求仍在增长），以及能把单位算力卖出更高 ARR 的云厂商。Serenity 公开推文曾转述市场信息，称 DeepSeek 与智谱正在开发定制 ASIC 以绕开对单一供应商的依赖【9】；这条线属于投资者解读，需要公司披露验证，但它指向定制芯片、先进封装与配套网络的结构性机会。

其次是内存带宽与互联：DeepSeek 模型以长上下文、大专家并行著称，推理对 HBM/DRAM 容量与 NVLink/光互联带宽敏感。Serenity 此前把“DeepSeek Engram v4”与 CXL 内存池联系在一起，指向 CXL 控制器与互联环节（如 Astera、博通、Marvell 所在的美国供应链）【10】；这是投资者推演的受益路径，不是公司事实，必须用订单与财报验证。

受益的还有工程效率环节：MoK 这类开源工程把效率红利绑定在 NVL72 机架与配套网络（NVLink、光模块、液冷）上；凡是能帮助实验室“同瓦数卖出更多 token”的软硬件，都会在 ARR/吉瓦 上升期获得结构性需求。【6】【7】

受压环节：纯裸算力租售（Neocloud）与依赖低价 API 的下游应用。若头部实验室持续提价并自行消化高价值调用，裸算力中间商的价差会被压缩；依赖 DeepSeek 低价 API 的套壳应用，则要承受成本上升或被迫涨价。存储与 PCB 等环节更多跟随总算力投放，属于“总量受益、价格分化”。

  • 受益：稀缺算力持有者、GPU/ASIC、内存带宽与互联、NVL72 配套。
  • 受压：裸算力 Neocloud、低价 API 套壳应用。
  • 边界：公司级映射需用订单与财报验证，本文不提供买入清单。

  • 错误一：把短期涨价当长期拐点。
  • 错误二：把第三方 ARR/吉瓦 估算当公司事实。
  • 核心观测：涨价后的调用量弹性、ARR/吉瓦 环比、免费流量占比。

先说结论：涨价是真的，但更可能是长期成本下行中的一次短暂再定价

8月6日，DeepSeek 在官方渠道预告，计划近期对 API 服务整体上调价格，预计涨幅较大，具体方案以正式通知为准。【1】同一天前后，市场开始用“token 定价权”重新讲述这个故事：有的测算 V4-Pro 名义毛利率可达 90% 至 97%、扣除免费流量后真实毛利率约 72% 至 81%【4】；有的转述第三方估算称，每吉瓦推理容量对应的年化收入今年已上升约 50%、达到约 300 亿美元【5】。两条线索合在一起，最自然的解读是“价格战结束、涨价周期开启”。

本文的判断是：DeepSeek 涨价是真实信号，但它更像“算力稀缺乘以需求二次加速”下的短期再定价，而不是单位 token 成本长期下行趋势的逆转。模型架构、芯片代际和推理工程仍在快速降本——MoE 训练吞吐刚刚被开源工程证明还能再提高 40% 以上【6】【7】。真正决定产业链价值分配的，不是某一次涨价，而是用量弹性能否持续跑赢价格波动，以及谁能把效率提升变成利润，而不是只让利给用户。

因此，本文要回答一个可证伪的问题：DeepSeek 涨价与 300 亿美元/吉瓦的 ARR，究竟是“价格战结束的拐点”，还是“长期成本下行曲线上的一次短暂再定价”？如果涨价落地后付费调用量显著下滑，说明定价权只是暂时的；如果涨价同时用量仍增长、头部实验室 ARR 持续上修，说明稀缺算力确实拥有了定价权。两种结果对应完全不同的投资含义。

  • 官方事实：涨价预告属实，但幅度与生效时间未定。【1】
  • 关键推断：短期定价权来自稀缺，不改变长期单位成本下行。
  • 证伪锚点：涨价后的调用量弹性与 ARR/吉瓦 环比方向。

官方事实：涨价预告、现行价目表与尚未生效的峰谷定价

按公开转述的官方口径，DeepSeek 于 8 月 6 日预告将对全部 API 服务整体上调价格，并强调“预计涨幅较大”，具体方案以正式通知为准。本次运行中，官方价格页无法直接访问（访问被限制），涨价预告与价目表经中新网、财联社等媒体转述核对，因此全部标注为“官方公告/媒体转述”层级，最终以官方正式通知为准。【1】

现行价目表（媒体转述口径，截至 2026-08-06）：V4-Flash 为每百万 tokens 0.02 元（缓存命中）、1 元（缓存未命中输入）、2 元（输出）；V4-Pro 为每百万 tokens 0.025 元、3 元、6 元。另有媒体转述的峰谷定价方案：北京时间 9:00 至 12:00、14:00 至 18:00 为高峰时段，价格约为基础价的 2 倍；该方案尚未生效。【1】

从量看，第三方统计口径显示，V4-Flash 在 8 月 1 日单日处理约 8 万亿 tokens，其中约 5 万亿为免费流量、3 万亿为付费流量【第三方口径，原始链接待核】；8 月 4 日又因访问量空前出现容量压力，官方确认了当日服务压力【媒体转述】。若按此拆算，免费流量占比仍然很高，这也解释了为何市场普遍推断涨价的重要动机之一是“过滤低价与免费调用、把稀缺算力留给付费能力更强的用户”——该动机属于市场推断，不是官方表述。

融资与估值背景同样重要：8 月 5 日，21财经与《财经》等媒体报道 DeepSeek 新一轮融资前估值约 5000 亿元人民币、拟融资约 500 亿元【媒体转述，原始链接未归档】。对一家仍需要持续购买算力、扩大集群的私营公司，涨价与融资可以看作同一件事的两面：让 API 业务更接近自我造血，同时为下一轮资本开支定价。

  • 已确认：涨价预告（官方公告，媒体转述）；具体幅度与生效时间未定。【1】
  • 现行价：V4-Flash 0.02/1/2 元、V4-Pro 0.025/3/6 元每百万 tokens（转述口径）。【1】
  • 背景：单日约 8 万亿 tokens（第三方统计）、8/4 容量承压、约 5000 亿元融资前估值（媒体转述）。

账本拆解：官方 545% 口径与 V4-Pro 的名义/真实毛利率

讨论定价权之前，先看成本账。DeepSeek 官方系统论文（2025 年 3 月，V3/R1 线上推理系统）披露：日均使用约 226.75 个 H800 节点，单日处理约 6080 亿输入 tokens 与 1680 亿输出 tokens；按每张卡每小时 2 美元的租赁价格测算，单日 GPU 成本约 8.7 万美元；若全部按当时 R1 的 API 价格计费，理论日收入约 56.2 万美元，对应理论收入成本利润率约 545%。【3】

官方论文同时强调，545% 是理论口径：网页端与 App 免费、夜间折扣、低价版本与未完全计费流量，都会大幅压低真实收入。【3】因此 545% 不能直接当真实利润率，但它证明了一个方向性事实：DeepSeek 的推理成本远低于名义牌价，账面并不存在“每卖一个 token 就亏钱”的困境。

到 V4，公开测算进一步放大这个结论。公众号《傅里叶的猫》按 V4-Pro 名义牌价、模型推理计算量下降与缓存机制改善推算，名义毛利率可达 90% 至 97%；把免费流量、折扣等因素扣除后，作者估计真实毛利率约在 72% 至 81% 区间。【4】这是作者推断而非官方披露，但即使取下限 72%，也意味着涨价并非因为“无法覆盖成本”，而是主动选择让价格与未来资本开支、稀缺算力对齐。

账本结论：涨价更多是“利润再分配”与“需求筛选”，而不是“成本倒逼”。这决定了后续观察重点应从“DeepSeek 亏不亏钱”转向“涨价之后，付费调用量还能不能继续增长”。

  • 官方口径：R1 时代理论收入成本利润率约 545%，但含大量免费流量，非真实利润率。【3】
  • 作者测算：V4-Pro 名义 90% 至 97%、真实约 72% 至 81%（公众号推断，未官方确认）。【4】
  • 解读：涨价更像主动定价与需求筛选，而非成本倒逼。

token 定价权落到数字上：8T tokens/日与 300 亿美元/吉瓦的 ARR

定价权的前提，是稀缺与需求同时存在。需求侧，第三方统计显示 V4-Flash 单日已处理约 8 万亿 tokens，8 月 4 日甚至因访问量空前出现容量压力；供给侧，研报平权转述的海外分析师测算称，每吉瓦推理容量对应的年化收入（ARR）今年已上升约 50%，达到约 300 亿美元/吉瓦，其中企业 API 口径可能更高，约 500 亿美元/吉瓦。【5】

300 亿美元/吉瓦是一个估算，不是官方数据，而且口径差异很大：消费者订阅、企业 API、内部训练占用会给出完全不同的数字。它的价值在于把“推理需求”翻译成“每单位算力能产生多少收入”，这是把 token 定价权落到产业链上的关键换算。按同一测算，2027 年推理算力可能从约 8 吉瓦增至约 31.5 吉瓦：若 ARR/吉瓦维持约 340 亿美元，实验室年化收入可达约 1.1 万亿美元；若效率提升继续推高 ARR/吉瓦，总盘子更高；若供给追上需求，ARR/吉瓦则可能回落至约 276 亿美元，对应约 8700 亿美元年化收入。【5】

三种情景的共同点是“推理收入体量巨大”，分歧在于价格与用量如何分配。DeepSeek 涨价正是在这个节点发生的：当推理需求经历第二次加速（Claude Code 之后，Fable/Codex 带来新一轮增长），撞上交付周期长达 12 至 18 个月的算力供给，掌握稀缺算力的实验室与云厂商自然获得短期定价权。【5】

对投资者而言，300 亿美元/吉瓦不是“利好标签”，而是一个需要逐季验证的换算系数：它上升，说明需求跑赢算力投放；它回落，说明供给开始追上、价格战可能重新开始。后者同样可能发生在 2027 年大规模算力集中上线之后。

  • 需求侧：V4-Flash 单日约 8 万亿 tokens（第三方统计）；8/4 容量承压（官方确认，媒体转述）。
  • 估值锚：ARR/吉瓦 约 300 亿美元，年内上升约 50%（第三方估算）。【5】
  • 情景：2027 算力 8 至 31.5 吉瓦时，ARR/吉瓦决定总盘子是 1.1 万亿、2.8 万亿还是 8700 亿美元级。【5】

杰文斯悖论与用量弹性：降价 10% 换 12% 至 18% 用量，涨价呢？

支持“涨价只是插曲”的最强证据，是需求弹性。美股AI投研速递引述 Exponential View 的研究：token 价格每下降 10%，用量上升 12% 至 18%，总 token 收入反而上升。【8】如果这个弹性系数成立，降价的净效果是薄利多销甚至薄利多赚，那么任何一次涨价都在给竞争对手让出份额，长期反而不可持续。

杰文斯悖论的关键前提，是“降价释放了原本负担不起的应用场景”。在 Agent 与编程场景里，成本从一次问答变成一条任务链：一个目标可能对应几十次模型调用与工具执行。单位 token 越便宜，开发者越愿意让 Agent 全天候运行、自我纠错、反复重试，总调用量呈非线性放大——这正是研报平权文章中“两次推理需求加速（Claude Code 与 Fable/Codex）”的直接含义。【5】

但弹性系数本身需要被验证，不能当作常数。12% 至 18% 的用量弹性来自第三方研究引用，而且“用量增长”不等于“收入增长”：降价 10% 只带来 12% 增量时，收入确实微增；如果涨价 50%（DeepSeek 峰谷 2 倍方案的上限），即使用量只回落 15%，收入仍大幅上升。这解释了为什么涨价与“用量仍在增长”可以同时成立——短期收入弹性主要由供给与定价权决定，长期才由杰文斯式的需求创造决定。

因此，杰文斯悖论不是“永远看多算力”的免检证书，而是一个需要逐季跟踪的弹性区间：调用量、任务时长、付费转化率与单 token 价格的乘积，才是真正的收入。

  • 引用弹性：价格每下降 10%，用量上升 12% 至 18%（Exponential View，第三方研究引用）。【8】
  • 结构因素：Agent 任务链把一次问答放大为几十次模型调用与工具执行。【5】
  • 关键区分：用量增长不等于收入增长，要看价格乘以用量的净乘积。

开源与工程效率：MoK 把 MoE 训练吞吐提升 41%，成本曲线还在往下走

成本曲线另一侧是工程效率。8 月 4 日，Cursor 开源 Mixture-of-Kittens（MoK）：一个面向 GB200/GB300 NVL72 机架的 MoE 训练 megakernel，官方称在其生产训练栈中把端到端 tokens/s 提升 1.41 倍；单层基准中，MXFP8 前向最快比公开基线快 2.37 倍。【6】【7】第三方转述的测试口径为：跨 512 块 GPU、多个 NVL72 机架的测试中，每 GPU tokens/s 从约 760.9 提升到 1070.2。【6】

MoK 的意义不在“训练快了 41%”本身，而在于它把 MoE 训练瓶颈从计算转向通信：当专家并行规模扩大，token 在不同 GPU 之间搬运的开销成为主约束。DeepSeek-V3 正是 671B 总参数、37B 激活参数的 MoE 架构，arXiv 技术报告披露其训练耗用约 278.8 万 H800 GPU 小时。【2】MoK 证明这类架构仍能通过软件工程继续挖出 40% 级吞吐，而且这条路与 NVL72 硬件形态深度绑定——效率提升与特定硬件深度绑定，既是机会也是门槛。

对成本曲线的含义：单位 token 成本的下行不仅来自芯片代际（H800 到 Blackwell 再到 Rubin），还来自把通信、调度、同步压进单个 kernel 的软件层。这类开源工程会加速“同代硬件处理更多 token”，也就是在名义涨价背后进一步压低真实单位成本。短期定价权来自稀缺，长期成本下行来自这些工程进步，两者并不矛盾。

需要保留的证据边界：MoK 的吞吐数字是 Cursor 自测口径，外部团队能否在不同负载下复现 2.37 倍与 1.41 倍仍需验证；且 MoK 面向 NVL72 专有硬件，不等于通用 MoE 效率的整体提升。【6】【7】

  • 事实：MoK 端到端 tokens/s 提升 1.41 倍，单层 MXFP8 前向最高 2.37 倍（Cursor 自测）。【6】【7】
  • 机制：MoE 训练瓶颈从计算转向通信，效率与 NVL72 深度绑定。【6】
  • 边界：自测口径，外部复现待验证。

通胀与通缩并存：短期定价权在卖方，长期定价权回到成本曲线

把前面各节放回同一条时间轴：短期（1 至 2 个季度）是“算力通胀”——稀缺供给、翻倍的高峰定价方案、约 5000 亿元的融资前估值；长期（2 至 3 年）是“单位成本通缩”——芯片代际、缓存命中率提升、MoE 通信优化与开源工程扩散，全部指向“完成同一任务所需算力与成本下降”。【1】【4】【5】【7】

两者的分界点不是某个价格事件，而是算力供给曲线。只要交付周期长达 12 至 18 个月、新增吉瓦跟不上需求，定价权就在卖方；当 2027 年新算力集中上线、ARR/吉瓦开始回落时，价格战可能以“降价加用量扩张”的形式重新开始。【5】DeepSeek 的涨价更接近前者：用价格筛选需求、为资本开支定价，而不是宣告成本曲线逆转。

对“AI 资本开支是否过热”的争论，这条时间轴给出了更精确的问题：不是“Capex 太多”，而是“Capex 在 2026 至 2027 年上线时，ARR/吉瓦能否守住 200 亿美元以上”。守得住，硬件投入可持续；守不住，第一轮价格战会先在推理 API 与裸算力租售中出现，再传导到 GPU 与内存订单。

这也是 Serenity 近期把 NVIDIA/OpenAI 融资结构概括为“信用与循环融资成为新约束”的同一逻辑：AI 基建的可持续性，最终由“算力到 token、token 到收入、收入到现金流”的转化效率决定，而不是由某一轮融资或某一次涨价决定。

  • 短期：稀缺驱动通胀，定价权在卖方。
  • 长期：效率驱动通缩，定价权回到谁成本低、谁生态强。
  • 分界：2027 供给集中上线时，ARR/吉瓦 是核心观测点。

收益传导：谁拿到涨价红利，谁在承担涨价成本

如果“涨价加用量增长”同时成立，收益首先流向掌握稀缺算力与定价权的环节：头部模型实验室（API 提价直接增厚收入）、GPU 与 ASIC 供应商（需求仍在增长），以及能把单位算力卖出更高 ARR 的云厂商。Serenity 公开推文曾转述市场信息，称 DeepSeek 与智谱正在开发定制 ASIC 以绕开对单一供应商的依赖【9】；这条线属于投资者解读，需要公司披露验证，但它指向定制芯片、先进封装与配套网络的结构性机会。

其次是内存带宽与互联：DeepSeek 模型以长上下文、大专家并行著称，推理对 HBM/DRAM 容量与 NVLink/光互联带宽敏感。Serenity 此前把“DeepSeek Engram v4”与 CXL 内存池联系在一起，指向 CXL 控制器与互联环节（如 Astera、博通、Marvell 所在的美国供应链）【10】；这是投资者推演的受益路径，不是公司事实，必须用订单与财报验证。

受益的还有工程效率环节：MoK 这类开源工程把效率红利绑定在 NVL72 机架与配套网络（NVLink、光模块、液冷）上；凡是能帮助实验室“同瓦数卖出更多 token”的软硬件，都会在 ARR/吉瓦 上升期获得结构性需求。【6】【7】

受压环节：纯裸算力租售（Neocloud）与依赖低价 API 的下游应用。若头部实验室持续提价并自行消化高价值调用，裸算力中间商的价差会被压缩；依赖 DeepSeek 低价 API 的套壳应用，则要承受成本上升或被迫涨价。存储与 PCB 等环节更多跟随总算力投放，属于“总量受益、价格分化”。

  • 受益：稀缺算力持有者、GPU/ASIC、内存带宽与互联、NVL72 配套。
  • 受压：裸算力 Neocloud、低价 API 套壳应用。
  • 边界：公司级映射需用订单与财报验证，本文不提供买入清单。

市场预期差与证伪条件

市场当前最容易犯的两个错误：一是把“DeepSeek 涨价”直接外推成“AI 硬件价格战结束、涨价周期开启”，忽略单位成本长期下行与 2027 年供给集中；二是把“300 亿美元/吉瓦 ARR”当作实验室盈利能力的现成证明，忽略它只是第三方估算，且不同口径差异巨大。【4】【5】

真正的预期差在于：定价权从“模型能力”单点转移到“算力稀缺加成本曲线控制”的组合。DeepSeek 涨价的意义不是“它赚了更多钱”，而是它第一次用价格信号表明，头部实验室认为自己有资格筛选用户、为资本开支定价。这种定价权一旦被验证（涨价后付费调用量仍增长），会重塑云厂商、Neocloud 与上游硬件之间的利润分配。

证伪条件（满足任一即应下调判断）：其一，涨价正式生效后，付费调用量或 API 收入环比显著下滑；其二，ARR/吉瓦 环比回落，或 2027 年算力集中上线后价格战重启；其三，头部实验室真实毛利率被证明远低于估算，例如免费流量占比远超预期；其四，涨价引发用户大规模迁移到国产替代模型，DeepSeek 份额不升反降。反向强化条件：涨价后用量仍增长、实验室 ARR 持续上修、云厂商推理收入增速同步抬升。

  • 错误一：把短期涨价当长期拐点。
  • 错误二：把第三方 ARR/吉瓦 估算当公司事实。
  • 核心观测：涨价后的调用量弹性、ARR/吉瓦 环比、免费流量占比。
